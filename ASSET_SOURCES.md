# Neko Nightfall - character asset sources

The prototype uses lightweight original/procedural meshes so the web preview stays dependency-free. These are the vetted character sources for the next art pass:

- [Kenney Blocky Characters](https://www.kenney.nl/assets/blocky-characters) - CC0 1.0, suitable for player/NPC prototypes.
- [Kenney Animated Characters Retro](https://www.kenney.nl/assets/animated-characters-retro) - CC0 1.0, useful for stylized horror enemies.
- [Quaternius Universal Base Characters](https://quaternius.com/packs/universalbasecharacters.html) - CC0, game-ready rigged characters with glTF/FBX/OBJ formats and Godot compatibility.
- [OpenGameArt CC0 3D Characters](https://opengameart.org/content/cc0-3d-characters) - additional CC0 references.

The visual target is an original, atmospheric survival-horror game: fixed dark courtyard, flashlight, scarce ammunition, hostile creatures, and an exit objective. Do not copy Resident Evil characters, logos, maps, sounds, or textures.
