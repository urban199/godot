# Generated Anime Asset Pack

Included:
- `references/`: generated art-direction boards for character, city, items, enemies and UI. These are concept references, not 3D models.
- `items/*.png`: individually generated-from-vector 2D UI item icons usable in inventory/pickup UI.
- `items/item_icon_atlas.png`: 4x3 icon atlas, 256px per cell.
- `environment/*.png`: stylized tileable-ish prototype material swatches for environment blockout.

The icon art and swatches are real image assets that can be imported into Godot. The reference boards are for guidance only and should not be assigned as a 3D model or PBR texture atlas. Existing gameplay and scenes are preserved. The new items are assets, not yet wired into the game's inventory logic.
